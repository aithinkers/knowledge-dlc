# Support

During public pre-release development, use GitHub issues for reproducible
defects and feature requirements. Search existing issues first and select the
bug or requirement form. This project does not yet offer compatibility or
response-time guarantees.

Do not use issues for vulnerabilities, credentials, personal information, or
restricted source material; follow [SECURITY.md](SECURITY.md). For Code of
Conduct concerns, use the confidential intake described in
[CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

Before filing a defect, search existing issues and include the K-DLC revision,
environment, minimal reproduction, expected behavior, actual behavior, and
redacted diagnostic output.
